# Kai Arcade OS

Kai Arcade OS is an offline-first family arcade cabinet for iPhone, iPad and laptop browsers. `index.html` is based on the original attached 20-game build and remains double-click playable — no build step or network connection is required.

## Included in this starter

- Cabinet-style dashboard with original generated hero art
- Local player profile, XP-ready level, wins, recent activity and Teddy Mode preference
- Shared audio feedback, pause-safe lifecycle, visibility pause and lightweight animation loop
- All original 20 rooms preserved: football, board games, Pool, Shooting Gallery, Darts, Bowling, Vegas Jackpot ’85 and Retro World of Snacks
- Upgraded hero artwork, touch-first sizing, restrained mobile effects, visibility pause safeguards and an F2 performance HUD
- Touch-friendly buttons, responsive layout and no hover-only controls

## Run

Open `index.html`. The save file is stored in browser `localStorage` under `kai-arcade-save`.
